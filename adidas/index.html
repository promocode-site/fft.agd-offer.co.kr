아디다스 프로모션코드 적용 순서

가격 할인은 담는 순간, 회원 쿠폰은 결제 직전에 붙습니다. 이 순서를 지키면 결제 후 소급이 안 되는 쿠폰을 놓치지 않습니다.

  1. adiClub 로그인과 쿠폰함 확인

    로그인 후 계정의 쿠폰함(바우처)에 생일·레벨업 쿠폰이 들어와 있는지, 사용 기간이 남았는지 확인하세요. 처음이면 가입하면서 이메일 수신에 동의해야 웰컴 쿠폰 메일을 받습니다.

    가입 한 번으로 139,000원 신발에서 13,900원이 빠집니다.

  2. 상품 구역 확인

    상품 페이지에서 정가·세일·아울렛 중 어디에 속하는지, '25% 추가 할인' 표시가 있는지, 협업·한정 상품인지 확인하세요.

    추가 할인 표시 하나로 44,500원 아울렛가에서 11,125원이 더 내려갑니다.

  3. 장바구니에서 반영 가격 확인

    아울렛 추가 할인은 입력 없이 장바구니 금액에 반영됩니다. 표시와 금액이 다르면 담은 사이즈·색상이 대상인지 다시 보세요.

  4. 결제 단계에서 쿠폰 선택 또는 프로모션 코드 입력

    계정 쿠폰은 목록에서 고르고, 웰컴 쿠폰은 이메일로 받은 문자열을 프로모션 코드 칸에 넣습니다. 여러 장이 있으면 하나씩 바꿔 가며 할인액을 비교하세요.

    169,000원 신발이면 20% 쿠폰을 고를 때 15% 쿠폰보다 8,450원 덜 냅니다.

  5. 결제수단 선택과 최종 금액 확인
